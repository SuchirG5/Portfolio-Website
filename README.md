# Suchir Godavarthi | Personal Portfolio

Personal portfolio website presenting my experience, research, and projects across software development, applied machine learning, and aerospace engineering.

[View Portfolio](https://suchirg5.github.io/Portfolio-Website/portfolio.html)

### Overview

I am an Aerospace Engineering student at Purdue University, minoring in Artificial Intelligence. This website brings together my professional experience, technical interests, research, and project information.

### Technology

- HTML for page structure and content
- CSS for styling
- JavaScript for client-side behavior
- GitHub Pages for hosting

### Repository Structure

| File or directory | Purpose |
| --- | --- |
| `index.html` | Website entry page |
| `portfolio.html` | Education, experience, research, and skills |
| `projects.html` | Project information |
| `blog.html` | Blog page |
| `style.css` | Website styling |
| `script.js` | Client-side JavaScript |
| `Projects/` | Project-related files |
| `Images/Articles/` | Article-related images |

### View Locally

Download or clone the repository and open `index.html` in a browser. Open `portfolio.html` directly to view the professional portfolio page.

### Scope

This repository contains the source for the portfolio website. Projects and professional experience described on the site are separate from the website implementation; their descriptions do not imply that their source code is included here.
